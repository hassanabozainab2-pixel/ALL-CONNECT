# ALL CONNECT — Android MVP

مشروع أندرويد أولي يجمع إشعارات التطبيقات التي يسمح نظام Android للتطبيق بقراءتها بعد منح إذن Notification Access يدويًا.

## الحدود والخصوصية
- لا يقرأ المحادثات الداخلية ولا يتجاوز أذونات التطبيقات.
- لا يرسل ردودًا تلقائية إلى واتساب أو غيره.
- يحفظ معاينات الإشعارات محليًا على الجهاز فقط، دون خادم أو اشتراك.
- هذه نسخة Debug للتجربة وليست إصدار متجر موقّعًا.

## ملفات المصدر
يوجد أرشيف المصدر الكامل في `source/ALL-CONNECT-Android-MVP.zip`. يقوم GitHub Actions بفكّه وبناء APK عند كل تحديث إلى main.

## APK
من تبويب Actions افتح آخر تشغيل ناجح، ثم نزّل Artifact باسم `ALL-CONNECT-debug-apk`.
