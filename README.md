# ALL CONNECT — Android MVP

تطبيق أندرويد أولي يجمع معاينات الإشعارات التي يسمح نظام Android للتطبيق بقراءتها بعد منح إذن **Notification Access** يدوياً.

## الموجود في النسخة الحالية
- شاشة عربية تعرض الإشعارات المحفوظة.
- زر يفتح إعدادات أندرويد لتفعيل صلاحية الوصول.
- عرض اسم التطبيق وعنوان الإشعار والنص ووقت الوصول.
- الاحتفاظ بآخر 100 إشعار على الجهاز.
- مسح سجل الإشعارات من داخل التطبيق.

## الخصوصية والحدود
- لا يقرأ المحادثات الداخلية ولا يتجاوز أذونات التطبيقات.
- لا يرسل ردوداً تلقائية إلى واتساب أو غيره.
- معاينات الإشعارات قد تحتوي على معلومات خاصة؛ تُحفظ محلياً على الجهاز ولا تُرفع إلى خادم.
- لا تمنح صلاحية الوصول إلا إذا كنت موافقاً على عرض معاينات إشعارات التطبيقات.
- هذه نسخة Debug للتجربة وليست إصدار متجر موقّعاً.

## بناء APK
يقوم GitHub Actions ببناء التطبيق عند كل تحديث إلى فرع `main`. من تبويب **Actions** افتح آخر تشغيل ناجح ثم نزّل Artifact باسم `ALL-CONNECT-debug-apk`.
